## DataS-DHSC (Archived)

This GitHub organisation has been decommissioned and is now archived.

All repositories in this organisation have been archived as read-only and no new repositories can be created here. Existing projects have been migrated to the new official GitHub organisation [dhsc-govuk-internal](https://github.com/dhsc-govuk-internal).

Nothing has been deleted as part of this process. However, access to private and internal repositories in this organisation has been removed.


### Setup and Access
For guidance on setting up Git and GitHub, including how to get access to the the new official GitHub organisations [dhsc-govuk](https://github.com/dhsc-govuk) and [dhsc-govuk-internal](https://github.com/dhsc-govuk-internal/), please see:  
Data Science Front Door > Data Platforms and Software > Software Installation and Tooling > Git Installation Guide
